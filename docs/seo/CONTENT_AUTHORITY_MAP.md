## Decisions explicitly NOT to create a new page

- **Itinerary page:** not created. `things-to-do-maamigili.html` already contains a lightweight itinerary-suggestion tip box; no Trends/GSC evidence this pass justified a dedicated standalone itinerary page. Per instruction, a page is not created "just to complete a checklist."
- **Cost/planning page:** not created. `maldives-holiday-cost.html` already fully covers general market ranges, a real cost example, and additional budget items. Creating a second page would duplicate existing, working content.
- **Whale-shark/manta page rewrite:** not performed. Direct inspection this pass found no genuine content weakness in either existing page — both are substantial and well-structured. The real gap for this cluster is indexing (`INDEXING_ANALYSIS.md`), not content, and is out of scope for a content-creation workstream.

## Localization decision (explicit, per instruction)

`getting-to-maamigili.html` ships **English-only** this pass:

- **Reasoning:** the page was justified by one specific, narrow piece of evidence — a legacy `.com` page ranking for an English-language query. There is no current evidence (Trends, GSC, or otherwise) of non-English demand specifically for this transport/trip-prep content cluster, unlike the whale-shark cluster where multi-market evidence already exists project-wide.
- **Mechanism:** the page is registered in `sitemap.xml` (self-referencing `en`/no hreflang cluster — a single-language page correctly carries no hreflang tags at all, per Google's own guidance) and in `test/phase12-preservation-manifest.json` (`"translated": false`), but is **not** added to `build-i18n-pages.js`'s `PAGES` array — so it does not generate 10 thin, untranslated locale mirrors, honoring the explicit instruction against unnecessary thin locale pages.
- **Consequence, stated honestly:** nav/footer links to this page on the other 12 (soon-to-be-localized) source pages will show the English label "Getting to Maamigili" even inside a fully-translated Russian/German/etc. page — this is a deliberate, minor, and defensible trade-off (the destination page itself is English, so an English label sets the correct expectation) rather than a bug.
- **Revisit trigger:** if GSC shows real non-English query/impression volume for this URL after it accumulates data, full localization becomes evidence-justified and should be proposed as its own future phase.
