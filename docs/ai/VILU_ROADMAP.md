Visual Crossing is a solid second choice (also commercially-licensed free, includes sunrise/sunset/moon data) but requires a visible attribution credit at that tier; OpenWeatherMap's free current-weather API is generous but its per-day-forecast-with-sunrise/sunset product ("One Call 3.0") only has 1,000 free calls/day before pay-per-call; Tomorrow.io's commercial terms at production scale were not clearly published. **Security note from research:** none of these providers offer scoped browser tokens — all use one static key — so a thin server-side proxy/cache (not a raw client-side key) is the recommended architecture regardless of provider, which also keeps real request volume far inside any free tier. No provider has been selected or purchased; no key has been added.
