# VILU — Master Context

**Read this file, and the other six `docs/ai/VILU_*.md` files, before any substantial Vilu work.** See `VILU_CURRENT_STATE.md` for the session-startup checklist.

---

## 1. What Vilu is — two connected identities

**1. Vilu Residence** — the owner's real six-room guesthouse in Maamigili, South Ari Atoll, Maldives. A real, operating, local-island business.

**2. Vilu** — the broader Maldives / South Ari holiday and travel brand built around it.

Long-term positioning: *"Vilu — a South Ari holiday platform that owns its own accommodation."*

**Hard rule:** Vilu Residence must never be presented as a resort, or implied to have resort facilities, a private resort island, facilities that don't exist, wildlife-sighting guarantees, or unverified services. It is a boutique/local-island guesthouse — six rooms, not sixty. See `VILU_PROTECTED_CONTRACTS.md` §"Truthful positioning".

## 2. Primary business target

The website must not stay "a pretty guesthouse website." Target: **Vilu = a major South Ari / Maamigili travel authority and direct holiday-selling platform.**

Commercial priorities, in order:
1. Sell complete Maldives / South Ari holiday packages directly.
2. Grow direct Vilu Residence accommodation bookings.
3. Build Vilu into a trusted South Ari destination authority.
4. Acquire international organic traffic.
5. Build international agency/partner distribution.
6. Own important South Ari travel-planning search intent.
7. Increase direct enquiries, reduce dependence on OTAs/third parties.
8. Eventually build an ecosystem around accommodation, experiences, packages, and related Vilu brands (see §7 below).

## 3. Two separate customer funnels — do not merge them

**Package funnel:** Google / Yandex / AI search / Google Maps / Google Images / YouTube / Trip.com·Ctrip / Xiaohongshu / WeChat referrals / Telegram / VK / social / travel agencies / OTAs / digital PR / backlinks → Vilu destination content → South Ari/Maamigili knowledge → Holiday Packages → package enquiry → WhatsApp/email/Vilu conversion.

**Accommodation funnel:** visitor → Vilu Residence → live room availability → PMS → direct accommodation booking.

These are separate systems. Do not route package selling through the accommodation PMS unless explicitly redesigned later. Preferred bridging copy: *"Prefer to arrange accommodation separately? Check live availability →"*

## 4. Commercial hierarchy the site should communicate

WHY SOUTH ARI? → WHY MAAMIGILI? → WHAT CAN I EXPERIENCE? → WHICH HOLIDAY PACKAGE FITS ME? → WHERE WILL I STAY? → BOOK / ENQUIRE.

Vilu should feel like *a Maldives holiday platform*, not *a small hotel site with a few excursion links*.

## 5. Design north star

Cinematic, premium, luxurious, editorial, advanced, modern, digital, clean, spacious, photography-first, emotionally compelling, easy to understand, easy to buy from.

**Cinematic photography > decorative animation.** Never add: floating whale sharks/mantas/turtles, bubble fields, particle systems, random drifting objects, WebGL-for-decoration, cursor-following gimmicks, scroll-jacking, cheap parallax everywhere, multiple autoplay videos, oversized blank gradients, huge empty transition screens. (These were literally shipped once and then removed — see `VILU_CHANGELOG.md`.)

Motion hierarchy: micro interaction → interface motion → one strong cinematic moment → calm. Page rhythm: still → subtle movement → cinematic moment → calm again.

## 6. Dark / Light visual system

**Dark theme:** deep navy/near-black, cinematic Maldives-night feeling, warm amber/gold accent, rich real photography, high contrast, premium mood. First-ever visit = dark (OS color-scheme preference deliberately not consulted — approved decision, see `VILU_DECISIONS.md`).

**Light theme:** warm ivory/cream, navy typography, warm amber accents, bright island editorial feeling, real photography carrying the page. Must never become huge cream empty areas, washed-out photography, white fog patches, or low-contrast gradients.

Manual theme choice persists via the existing consent/session-aware mechanism (`theme.js`) — do not regress it.

The owner-supplied Dark/Light reference screenshots are **visual/art-direction references only** — they set photography-first composition, serif editorial headings, warm amber restraint, deep cinematic dark backgrounds, warm ivory light backgrounds, large photographic storytelling, clean luxury navigation/footer, premium package presentation, atmospheric accommodation imagery. **They are not business data** — never copy fictional text/prices/package details shown in those mockups into the real site.

## 9. The final vision

A visitor should be able to: discover South Ari → understand Maamigili → see real current destination conditions → learn about whale sharks/mantas/snorkeling/diving → understand transport and trip preparation → compare holiday options → choose a Vilu holiday package → see authentic accommodation → check live room availability → book accommodation → enquire about packages → trust the business → use the site in their own language → find Vilu through Google/Yandex/AI/social/travel platforms.

**Cinematic destination storytelling + real local expertise + useful travel information + holiday package commerce + direct accommodation booking + international search authority.** That is the core Vilu vision — see `VILU_ROADMAP.md` for how every phase ladders up to it.
